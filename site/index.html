How it works

  1. Paste the command

    Any terminal on the computer where you use Claude Code or Codex. It runs straight from the GitHub repository.

  2. It reads what your agents already keep

    For Claude Code, the /stats cache and the session transcripts in ~/.claude; for Codex, the sessions in ~/.codex. Both can share one card, and no day is counted twice.

  3. Tap through, save your card

    One HTML file opens in your browser. The last slide saves your card.

Your history stays on your computer

  • Nothing is uploaded.It reads local files and writes one page that makes no network requests.
  • The card shows totals only.No prompts, no file names, no project names. A test fails if any of them reach the page.
  • You can read all of it.About 800 lines of code, no dependencies, MIT licensed.

Questions

Why do some months look empty?

Claude Code deletes session transcripts after 30 days by default. agent-wrapped also reads the /stats cache, which goes back further but only up to the last time you ran /stats. Run /stats once, then run agent-wrapped again. For a full year next time, set "cleanupPeriodDays": 365 in ~/.claude/settings.json.

I used more than one computer this year

History is kept per computer, not per account. On the other computer, run /stats once in Claude Code, then npx github:openyard-cloud/agent-wrapped --export wrapped-laptop.json. Copy the file over and run npx github:openyard-cloud/agent-wrapped --add wrapped-laptop.json. The file holds counts only.

What does "value at API prices" mean?

Claude Code's own estimate of what the same usage would cost on the API. On a subscription, it isn't what you paid.

How is the longest session measured?

By active time. Pauses longer than 30 minutes are left out, so a session left open overnight doesn't count as twelve hours.

Does it work with Codex, Gemini CLI or Cursor?

Codex, yes: it reads ~/.codex, and if you use both agents you get one card for the two. Gemini CLI and Cursor not yet. Pull requests are welcome.

Can I run it as a slash command?

Yes. Run claude plugin marketplace add openyard-cloud/agent-wrapped and claude plugin install agent-wrapped@agent-wrapped, then type /wrapped.

Is this made by Anthropic or OpenAI?

No. agent-wrapped is an independent open-source project. Claude and Claude Code are products of Anthropic; Codex is a product of OpenAI.
