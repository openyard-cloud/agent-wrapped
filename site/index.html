How it works

Three steps, all on your machine

Run it

Paste the command into any terminal. It runs straight from the GitHub repository: no account, no API key.

It reads your history

Claude Code's /stats cache and the session transcripts in ~/.claude, merged so no day is counted twice.

Tap through, save your card

One HTML file opens in your browser. The last slide saves your card as a PNG.

Privacy

Your history stays yours

  • Nothing leaves your computer. It reads local files and writes one page that makes no network requests.
  • The card shows totals only. No prompts, no file names, no project names. A test checks that they never reach the page.
  • Open source, no dependencies. About 800 lines you can read before you run it.
FAQ

Questions

Why do some months look empty?

Claude Code deletes session transcripts after 30 days by default. agent-wrapped also reads the /stats cache, which goes back to your first session but only up to the last time you ran /stats. Run /stats once, then run agent-wrapped again. For a full year next time, set "cleanupPeriodDays": 365 in ~/.claude/settings.json.

What does "value at API prices" mean?

Claude Code's own estimate of what the same usage would cost on the API. If you're on a subscription, it isn't what you paid.

How is the longest session measured?

By active time. Pauses longer than 30 minutes are left out, so a session left open overnight doesn't count as twelve hours.

Does it work with Codex, Gemini CLI or Cursor?

Not yet. Claude Code comes first; other agents are on the list. Pull requests are welcome.

Can I run it as a slash command?

Yes. Install the plugin with claude plugin marketplace add openyard-cloud/agent-wrapped and claude plugin install agent-wrapped@agent-wrapped, then type /wrapped.

Is this made by Anthropic?

No. agent-wrapped is an independent open-source project. Claude and Claude Code are products of Anthropic.
